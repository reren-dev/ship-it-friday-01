## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line commit message to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program
validates the line against the competition gate first: 1–159 characters,
a single line, not only whitespace, and shaped like a real commit message
(`type: subject`). Two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
